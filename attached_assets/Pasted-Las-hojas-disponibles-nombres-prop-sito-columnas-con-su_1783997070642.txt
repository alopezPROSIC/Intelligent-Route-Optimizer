🔧 CÓMO USAR ESTE JSON EN OTRO SISTEMA
Opción 1: Alojar el JSON en una hoja oculta del mismo Spreadsheet
Crea una nueva hoja llamada _config.

En la celda A1, pega el JSON completo.

El sistema puede leer esa hoja para autoconfigurarse.

Ventaja: La configuración viaja con el archivo.

Opción 2: Descargar el JSON desde una URL pública
Sube el archivo a un repositorio de GitHub o a un servicio de almacenamiento.

El sistema hace un GET a esa URL.

Ventaja: Puedes actualizar la configuración sin modificar el spreadsheet.

🐍 EJEMPLO DE CÓDIGO PYTHON PARA AUTOCONFIGURACIÓN
python
import gspread
import json
import requests
from oauth2client.service_account import ServiceAccountCredentials

# 1. Cargar configuración (desde URL o desde hoja)
def cargar_configuracion():
    # Opción A: Desde URL
    config_url = "https://raw.githubusercontent.com/tu-repo/config.json"
    response = requests.get(config_url)
    return response.json()
    
    # Opción B: Desde hoja _config (necesitas autenticación primero)
    # config_sheet = spreadsheet.worksheet("_config")
    # return json.loads(config_sheet.acell('A1').value)

# 2. Conectar a Google Sheets
config = cargar_configuracion()
scope = ["https://spreadsheets.google.com/feeds", "https://www.googleapis.com/auth/drive"]
creds = ServiceAccountCredentials.from_json_keyfile_name("creds.json", scope)
client = gspread.authorize(creds)
spreadsheet = client.open(config["spreadsheet_name"])

# 3. Leer una hoja usando la configuración
sheet_name = "REPORTE"
sheet_config = config["sheets"][sheet_name]
worksheet = spreadsheet.worksheet(sheet_name)
data = worksheet.get_all_records()

# 4. Mapear datos a objetos con nombres amigables
# Usamos la configuración para saber qué columna es cada campo
for row in data:
    # row es un dict con claves = nombres originales de columnas (ej. "FECHA LLEGADA...")
    # Queremos convertirlo a un dict con claves = nombres lógicos (ej. "fecha_llegada_solicitud")
    objeto = {}
    for campo_logico, col_info in sheet_config["columns"].items():
        nombre_original = col_info["name"]
        objeto[campo_logico] = row.get(nombre_original)
    # Ahora podemos usar `objeto` con nombres consistentes
    print(objeto["pedido"], objeto["cliente"])
✅ BENEFICIOS DE ESTA ESTRATEGIA
Autoconfiguración total: El sistema lee el JSON y sabe exactamente qué hojas existen, qué columnas tienen y cómo se relacionan.

Mantenibilidad: Si añades una columna nueva, solo actualizas el JSON (y el sistema lo detecta automáticamente).

Reducción de errores: No tienes que hardcodear índices de columnas (0, 1, 2, ...) en tu código.

Multilenguaje: El JSON puede ser consumido por Python, Node.js, Java, etc.
